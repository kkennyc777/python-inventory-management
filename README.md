Inventory Management System

This is my fourth Python project, developed as the next step in my journey to strengthen and consolidate my Python fundamentals.

The goal of this project is to build a functional Inventory Management System while learning and reinforcing key concepts such as:

Object-Oriented Programming (OOP), classes, objects, attributes, and methods
Separation of responsibilities between classes
Working with lists and collections of objects
Functions, parameters, return values, and scope
Loops, conditionals, and data validation
Searching, updating, and deleting data
Error and exception handling
JSON data persistence
File handling
Organizing Python code into multiple modules
Debugging and basic testing
Writing cleaner and more maintainable Python code

Unlike my previous projects, this project will gradually evolve from a simple Python script into a more structured application. I am building each feature progressively to understand why the code works, rather than simply focusing on the final result.

This repository will also document that progression through Git commits as new concepts and features are implemented.
